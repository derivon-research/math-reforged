# 线性方程组

矩阵方程

$$
Ax=b
$$

把 $m$ 个关于 $n$ 个未知数的线性方程统一写成一个对象。矩阵 $A$ 和右端向量 $b$ 已知，目标是寻找系数向量 $x$。按列看，问题是“哪些列组合产生 $b$”；按行看，第 $i$ 个方程是 $A$ 的第 $i$ 行与 $x$ 的点积等于 $b_i$。

方程组可能有唯一解、无解或多解。仅写成 $Ax=b$ 不预设其中哪一种情况成立。

> 来源：Strang, 5th ed., §1.1 Worked Example 1.1C, p. 7；§1.3, pp. 23-24；§2.1, pp. 31-45 展开行图像、列图像及矩阵形式。
