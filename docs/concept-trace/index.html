对角线之和为何属于算子本身

对 n×nn\times nn×n 矩阵 AAA，定义

tr⁡A=A1,1+⋯+An,n.\operatorname{tr}A=A_{1,1}+\cdots+A_{n,n}.trA=A1,1​+⋯+An,n​.

关键恒等式是，只要 ABABAB 与 BABABA 都是方阵，

tr⁡(AB)=tr⁡(BA).\operatorname{tr}(AB)=\operatorname{tr}(BA).tr(AB)=tr(BA).

一般并没有 AB=BA$；只有迹相等。若 $B=S^{-1}AS，则

tr⁡B=tr⁡(S−1AS)=tr⁡(ASS−1)=tr⁡A.\operatorname{tr}B =\operatorname{tr}(S^{-1}AS) =\operatorname{tr}(ASS^{-1}) =\operatorname{tr}A.trB=tr(S−1AS)=tr(ASS−1)=trA.

同一算子在不同基下的矩阵相似，所以可定义 tr⁡T=tr⁡M(T)\operatorname{tr}T=\operatorname{tr}\mathcal M(T)trT=trM(T) 而不注明基。

与特征值的关系

在复空间上取上三角基或若当基，主对角元就是按代数重数排列的特征值，因此

tr⁡T=λ1+⋯+λn\operatorname{tr}T=\lambda_1+\cdots+\lambda_ntrT=λ1​+⋯+λn​

其中重复计数。实算子的非实特征值在复化后成共轭对，和仍为实数。

例子与规则

tr⁡(abcd)=a+d.\operatorname{tr} \begin{pmatrix}a&b\\c&d\end{pmatrix}=a+d.tr(ac​bd​)=a+d.

迹满足线性性和 tr⁡(ST−TS)=0\operatorname{tr}(ST-TS)=0tr(ST−TS)=0。但 tr⁡(ST)=tr⁡S tr⁡T\operatorname{tr}(ST)=\operatorname{tr}S\,\operatorname{tr}Ttr(ST)=trStrT 一般错误；乘法性属于行列式。

迹只给出特征值总和，无法单独恢复算子或全部谱。许多不同矩阵有同一迹；它是有用的不变量，不是完整分类量。
