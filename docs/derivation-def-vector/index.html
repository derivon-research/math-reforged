从 Fn\mathbb F^nFn 提炼向量空间公理

为什么要离开坐标，但保留运算

唯一的 tail 前提“数域与有限有序组”已经提供：

  • 数域 F∈{R,C}\mathbb F\in\{\mathbb R,\mathbb C\}F∈{R,C} 及其标量算术；
  • 有限组 Fn\mathbb F^nFn ；
  • Fn\mathbb F^nFn 中逐坐标加法、零组、加法逆元与标量乘法。

这个前提的作用不是告诉我们“向量空间已经存在”，而是给出一个可检查的模型。 后面还要处理函数与无限序列，所以现在要问：

Fn\mathbb F^nFn 的哪些运算规律不依赖坐标外形，可以原封不动地迁移到别的对象？

我们将逐项抽取这些规律，最后才把满足它们的结构命名为向量空间。

先确定运算的输入与输出类型

对 x,y∈Fnx,y\in\mathbb F^nx,y∈Fn，逐坐标相加仍得到 Fn\mathbb F^nFn 中的元素； 对 λ∈F\lambda\in\mathbb Fλ∈F 与 x∈Fnx\in\mathbb F^nx∈Fn，缩放结果也仍属于 Fn\mathbb F^nFn。

为了把这一类型信息推广到任意集合 VVV，定义 1.19 要求两种运算分别是函数

+:V×V⟶V,+:V\times V\longrightarrow V,+:V×V⟶V, F×V⟶V.\mathbb F\times V\longrightarrow V.F×V⟶V.

写出陪域 VVV 就已经说明封闭性。这里不能只说“ u+vu+vu+v 有定义”，还必须保证 结果仍是同类对象。

从坐标中的标量规律提炼加法公理

取

x=(x1,…,xn),y=(y1,…,yn).x=(x_1,\ldots,x_n), \qquad y=(y_1,\ldots,y_n).x=(x1​,…,xn​),y=(y1​,…,yn​).

(x+y)k=xk+yk=yk+xk=(y+x)k.\begin{aligned} (x+y)_k &=x_k+y_k\\ &=y_k+x_k\\ &=(y+x)_k. \end{aligned}(x+y)k​​=xk​+yk​=yk​+xk​=(y+x)k​.​

x+y=y+x.x+y=y+x.x+y=y+x.

这就是教材结论 1.14 的证明路线。相同思路把 F\mathbb FF 中的加法结合律 逐坐标提升为

(x+y)+z=x+(y+z).(x+y)+z=x+(y+z).(x+y)+z=x+(y+z).

因此抽象空间应要求：对所有 u,v,w∈Vu,v,w\in Vu,v,w∈V，加法满足交换律与结合律。

为什么零向量和逆元必须作为存在条件

在 Fn\mathbb F^nFn 中，

满足 x+0=xx+0=xx+0=x。每个 x=(x1,…,xn)x=(x_1,\ldots,x_n)x=(x1​,…,xn​) 还有逐坐标逆元

  1. 存在一个 0V∈V0_V\in V0V​∈V，使所有 v∈Vv\in Vv∈V 都满足 v+0V=vv+0_V=vv+0V​=v ；
  2. 对每个 v∈Vv\in Vv∈V，存在 w∈Vw\in Vw∈V，使 v+w=0Vv+w=0_Vv+w=0V​。

这时还不能把 www 直接写成 −v-v−v，因为逆元的唯一性尚未证明。存在性也不能 省略：空集让某些全称公式空泛成立，却没有元素能担任零向量。

两条分配律分别连接什么

先固定 a∈Fa\in\mathbb Fa∈F。对每个坐标，

(a(x+y))k=a(xk+yk)=axk+ayk=(ax+ay)k.\begin{aligned} (a(x+y))_k &=a(x_k+y_k)\\ &=ax_k+ay_k\\ &=(ax+ay)_k. \end{aligned}(a(x+y))k​​=a(xk​+yk​)=axk​+ayk​=(ax+ay)k​.​

再固定 x∈Fnx\in\mathbb F^nx∈Fn。逐坐标使用同一条标量分配律可得

本步骤究竟建立了什么

tail 中的 F\mathbb FF 提供标量算术， Fn\mathbb F^nFn 提供可检查的具体模型。 我们逐项保留了真正参与运算的规律，由此定义向量空间，并用函数空间验证 它不依赖坐标外形。

本步骤没有证明“任意集合都是向量空间”，也没有声称所有向量空间都是 Fn\mathbb F^nFn。对一个新对象，仍需先定义两种封闭运算，再逐项验证公理。
