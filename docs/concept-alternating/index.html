交错多重线性型

从双线性推广到多个输入

mmm 重线性型是映射 ω:Vm→F\omega:V^m\to\mathbb Fω:Vm→F，并且固定其余变量后，对剩下的变量线性。若只要两个输入相同就有 ω(v1,…,vm)=0\omega(v_1,\ldots,v_m)=0ω(v1​,…,vm​)=0，则称 ω\omegaω 交错。

交换两个输入为何变号

在两个位置都放 u+vu+vu+v，交错性给出值为零。按这两个变量展开，含 (u,u)(u,u)(u,u) 与 (v,v)(v,v)(v,v) 的项为零，剩下两项之和为零。所以交换两项使值乘 −1-1−1。任意排列可分解为若干交换，因此

ω(vσ(1),…,vσ(m))=sgn⁡(σ)ω(v1,…,vm).\omega(v_{\sigma(1)},\ldots,v_{\sigma(m)}) =\operatorname{sgn}(\sigma)\omega(v_1,\ldots,v_m).ω(vσ(1)​,…,vσ(m)​)=sgn(σ)ω(v1​,…,vm​).

线性相关输入必给出零

若某个输入是其他输入的线性组合，多重线性展开后每项都会出现两个相同输入，故值为零。特别地，若 m>dim⁡Vm>\dim Vm>dimV，所有交错 mmm 重线性型只能是零。

最高次交错型空间是一维

若 dim⁡V=n\dim V=ndimV=n 并固定基 e1,…,ene_1,\ldots,e_ne1​,…,en​，把任意输入按基展开。交错性消去所有重复指标项，只留下基向量的排列。因此任意 nnn 重交错型完全由

ω(e1,…,en)\omega(e_1,\ldots,e_n)ω(e1​,…,en​)

这个标量决定，最高次交错型空间是一维。这让任意算子在该空间上的作用只能是乘一个标量，那个标量就是行列式。

二维模型 ω((a,b),(c,d))=ad−bc\omega((a,b),(c,d))=ad-bcω((a,b),(c,d))=ad−bc 是交错双线性型。平行输入时为零；交换输入后符号翻转。
