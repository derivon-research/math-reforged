同构

节点范围： 本节点只表示向量空间同构。换基是建立在同构、基与矩阵之上的独立节点。

不同外表下的同一种线性结构

可逆线性映射 T:V→WT:V\to WT:V→W 称为一个同构。若存在同构，就说 VVV 与 WWW 同构。它建立一一对应，同时保持加法和标量乘法，所以在一个空间中成立的纯线性关系可以无损搬到另一个空间。

有限维空间的分类极其简洁：

V≅W⟺dim⁡V=dim⁡W.V\cong W\quad\Longleftrightarrow\quad \dim V=\dim W.V≅W⟺dimV=dimW.

若两边都有维数 nnn，选基 v1,…,vnv_1,\ldots,v_nv1​,…,vn​ 和 w1,…,wnw_1,\ldots,w_nw1​,…,wn​，规定 Tvj=wjTv_j=w_jTvj​=wj​ 并线性延拓，就得到同构。反向则由可逆映射同时单射、满射以及维数公式得到。

坐标映射本身就是同构

给定 VVV 的基 B=(v1,…,vn)\mathcal B=(v_1,\ldots,v_n)B=(v1​,…,vn​)，坐标映射

CB:V→Fn,CB(v)=[v]BC_{\mathcal B}:V\to\mathbb F^n, \qquad C_{\mathcal B}(v)=[v]_{\mathcal B}CB​:V→Fn,CB​(v)=[v]B​

是同构。这说明每个 nnn 维空间都可用 Fn\mathbb F^nFn 计算，但坐标模型依赖所选的基。

换基矩阵

同一向量在两组基 B,C\mathcal B,\mathcal CB,C 下的坐标由可逆矩阵联系：

[v]C=PC←B[v]B.[v]_{\mathcal C}=P_{\mathcal C\leftarrow\mathcal B}[v]_{\mathcal B}.[v]C​=PC←B​[v]B​.

PC←BP_{\mathcal C\leftarrow\mathcal B}PC←B​ 的第 kkk 列是 B\mathcal BB 的第 kkk 个基向量在 C\mathcal CC 下的坐标。箭头说明输入是 B\mathcal BB 坐标、输出是 C\mathcal CC 坐标，能减少把矩阵方向写反的错误。

若 T∈L(V)T\in\mathcal L(V)T∈L(V)，它在两组基下的矩阵满足相似关系

[T]C=PC←B[T]BPB←C.[T]_{\mathcal C}=P_{\mathcal C\leftarrow\mathcal B}[T]_{\mathcal B}P_{\mathcal B\leftarrow\mathcal C}.[T]C​=PC←B​[T]B​PB←C​.

换基改变描述，不改变算子本身。后面的特征值、迹和行列式正是相似变换下不变的量。
