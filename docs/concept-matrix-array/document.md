# 矩阵

一个 $m\times n$ 矩阵是按 $m$ 行、$n$ 列排列的标量矩形表：

$$
A=(a_{ij}),\qquad 1\leq i\leq m,\quad 1\leq j\leq n.
$$

$a_{ij}$ 位于第 $i$ 行、第 $j$ 列。每一列可看成 $\mathbb R^m$ 中的向量，每一行可看成长度为 $n$ 的行向量。矩阵本身先是一个有限数据对象；它是否表示线性映射、方程组、差分算子或其他模型，要由后续解释决定。

本节点与现有“线性映射的矩阵”不同：后者要求先给定线性映射和两组基，本节点不要求这些抽象前提。

> 来源：Strang, 5th ed., §1.3, pp. 22-23；§§2.1, 2.4, pp. 36-38, 70-71 对行列索引、形状与运算范围作进一步展开。
