以基坐标表示线性映射

两个前提怎样汇合

线性映射由基向量的像决定；基又保证每个像在陪域中有唯一坐标。矩阵只是把这些坐标按列集中记录。

再设 S∈L(W,U)S\in\mathcal L(W,U)S∈L(W,U)，使用 WWW 的同一组中间基。先由 AAA 把 VVV 坐标变成 WWW 坐标，再由 B=M(S)B=\mathcal M(S)B=M(S) 变成 UUU 坐标，因此

结论

选定定义域和陪域的基后，线性映射与相应尺寸的矩阵一一对应。矩阵中的数字依赖基，但加法、数乘和复合的结构被完整保存。
