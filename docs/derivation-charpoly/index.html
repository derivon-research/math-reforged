特征多项式湮灭算子

前提如何进入

特征多项式已经由广义特征空间的维数定义；幂零结构让每个因子在相应分量上消失。本步骤的唯一 head 是 Cayley-Hamilton 定理。下文重述特征多项式公式只是前提回顾；最后与最小多项式的联系是定理成立后的推论，不是 tail。
