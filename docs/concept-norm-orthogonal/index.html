范数

节点范围： 本节点只表示内积诱导的范数。正交关系由内积独立定义；下文使用正交分解证明范数性质，但不把两者合并为一个概念。

从内积提取长度

在内积空间中定义

∥v∥=⟨v,v⟩.\|v\|=\sqrt{\langle v,v\rangle}.∥v∥=⟨v,v⟩​.

正定性保证根号内为非负实数，并且 ∥v∥=0\|v\|=0∥v∥=0 当且仅当 v=0v=0v=0。由内积公理可得 ∥av∥=∣a∣∥v∥\|av\|=|a|\|v\|∥av∥=∣a∣∥v∥。

若 ⟨u,v⟩=0\langle u,v\rangle=0⟨u,v⟩=0，称 uuu 与 vvv 正交。零向量与所有向量正交；“正交”不要求两个向量非零。

毕达哥拉斯与正交分解

若 u⊥vu\perp vu⊥v，展开得

∥u+v∥2=⟨u+v,u+v⟩=∥u∥2+∥v∥2.\|u+v\|^2 =\langle u+v,u+v\rangle =\|u\|^2+\|v\|^2.∥u+v∥2=⟨u+v,u+v⟩=∥u∥2+∥v∥2.

交叉项因为正交而消失。反向在实内积空间中由等式可推出正交；复空间中仅知交叉项实部为零，不足以推出内积为零。

三角不等式

展开 ∥u+v∥2\|u+v\|^2∥u+v∥2 并对交叉项应用 Cauchy-Schwarz，得到

∥u+v∥≤∥u∥+∥v∥.\|u+v\|\le\|u\|+\|v\|.∥u+v∥≤∥u∥+∥v∥.

所以内积诱导的范数满足距离应有的基本规则。不是每个范数都来自内积；本页只讨论由给定内积诱导的范数。
