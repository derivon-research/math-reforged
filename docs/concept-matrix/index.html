线性映射的矩阵

矩阵是选定基后的记录表

设 T∈L(V,W)T\in\mathcal L(V,W)T∈L(V,W)，定义域基为 v1,…,vnv_1,\ldots,v_nv1​,…,vn​，陪域基为 w1,…,wmw_1,\ldots,w_mw1​,…,wm​。每个 TvkTv_kTvk​ 都能唯一写成

Tvk=A1,kw1+⋯+Am,kwm.Tv_k=A_{1,k}w_1+\cdots+A_{m,k}w_m.Tvk​=A1,k​w1​+⋯+Am,k​wm​.

把这些系数放在第 kkk 列，得到 m×nm\times nm×n 矩阵

M(T,(v1,…,vn),(w1,…,wm))=(Aj,k).\mathcal M(T,(v_1,\ldots,v_n),(w_1,\ldots,w_m))=(A_{j,k}).M(T,(v1​,…,vn​),(w1​,…,wm​))=(Aj,k​).

矩阵的列数等于定义域基长度，行数等于陪域基长度。第 kkk 列不是随意计算出来的数字，而是 TvkTv_kTvk​ 在陪域基下的坐标。

为什么它能处理任意向量

若 v=x1v1+⋯+xnvnv=x_1v_1+\cdots+x_nv_nv=x1​v1​+⋯+xn​vn​，则线性性给出

Tv=∑k=1nxkTvk.Tv=\sum_{k=1}^n x_kTv_k.Tv=k=1∑n​xk​Tvk​.

因此坐标向量满足

[Tv]C=M(T,B,C)[v]B.[Tv]_{\mathcal C}=\mathcal M(T,\mathcal B,\mathcal C)[v]_{\mathcal B}.[Tv]C​=M(T,B,C)[v]B​.

这解释了矩阵乘向量的列组合规则：输入坐标 xkx_kxk​ 正是各列的权重。

对 (x,y)(x,y)(x,y)，矩阵乘法给出 x(2,1)+y(1,−1)=(2x+y,x−y)x(2,1)+y(1,-1)=(2x+y,x-y)x(2,1)+y(1,−1)=(2x+y,x−y)，与原映射一致。

运算对应关系

相同基约定下，$S+T$ 对应矩阵相加，$aT$ 对应矩阵数乘，复合 STSTST 对应矩阵乘积

M(ST)=M(S)M(T).\mathcal M(ST)=\mathcal M(S)\mathcal M(T).M(ST)=M(S)M(T).

乘积次序与函数复合一致：先作用 TTT，再作用 SSS。矩阵依赖基；换基会改变矩阵，却不会改变抽象线性映射。
