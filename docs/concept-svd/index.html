奇异值分解

节点范围： 本节点只表示奇异值分解。奇异值是由 T∗TT^*TT∗T 的特征值定义的独立前提节点。

特征分解做不到时怎么办

特征值只适用于同空间算子，并且算子未必可对角化。奇异值分解适用于任意有限维内积空间之间的线性映射 T:V→WT:V\to WT:V→W，包括不同维、不可逆和秩亏情形。

T∗TT^*TT∗T 是 VVV 上的正算子。其特征值非负，按重数写为 s_1^2,\ldots,s_n^2$；非负平方根 $s_j 称为 TTT 的奇异值。正奇异值的个数等于 rank⁡T\operatorname{rank}TrankT，零奇异值方向组成 null⁡T\operatorname{null}TnullT。

坐标无关的分解

存在 VVV 中的规范正交组 e1,…,ere_1,\ldots,e_re1​,…,er​ 与 WWW 中的规范正交组 f1,…,frf_1,\ldots,f_rf1​,…,fr​，以及正奇异值 s1,…,srs_1,\ldots,s_rs1​,…,sr​，使

Tv=∑j=1rsj⟨v,ej⟩fj.Tv=\sum_{j=1}^r s_j\langle v,e_j\rangle f_j.Tv=j=1∑r​sj​⟨v,ej​⟩fj​.

也可写成秩一算子之和 T=∑jsjfjej∗T=\sum_j s_j f_j e_j^*T=∑j​sj​fj​ej∗​。几何上：先把输入分解到正交方向 eje_jej​，沿每个方向按 sjs_jsj​ 非负缩放，再放到输出正交方向 fjf_jfj​。

矩阵版本

选取包含这些向量的规范正交基后，

A=UΣV∗,A=U\Sigma V^*,A=UΣV∗,

其中 U,VU,VU,V 幺正，$\Sigma$ 只有主对角线上可能出现非负奇异值。这里的 V∗V^*V∗ 是矩阵的共轭转置，不是抽象空间 VVV。

一个简单例子

对 T(x,y)=(3x,2y)T(x,y)=(3x,2y)T(x,y)=(3x,2y)，T∗T=diag⁡(9,4)T^*T=\operatorname{diag}(9,4)T∗T=diag(9,4)，奇异值为 3,23,23,2，标准基就是两侧奇异向量。若把输出再旋转，特征值可能失去直接几何意义，但奇异值仍是 3,23,23,2。
