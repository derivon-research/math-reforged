# 奇异矩阵

没有逆矩阵的方阵称为奇异矩阵。第 1 章的循环差分矩阵 $C$ 满足

$$
C(1,1,1)^T=0,
$$

所以不同输入可能得到同一输出，无法由输出唯一恢复输入。它的列向量落在同一平面内，只能产生满足 $b_1+b_2+b_3=0$ 的右端；其他右端对应的 $Cx=b$ 无解。

“存在非零 $x$ 使 $Cx=0$”是本章识别奇异性的核心证据。无解与多解不是两种无关故障，而是列组合未覆盖整个空间且表示不唯一的两个表现。

> 来源：Strang, 5th ed., §1.3, pp. 25-27；§§2.2, 2.5, pp. 47-53, 83-90 用缺失主元与消元零行给出计算判据。
