# 欧几里得范数

实坐标向量 $v=(v_1,\ldots,v_n)$ 的欧几里得范数是

$$
\|v\|_2=\sqrt{v_1^2+\cdots+v_n^2}=\sqrt{v\cdot v}.
$$

它是从原点到向量端点的直线长度。二维公式是勾股定理；更高维公式重复使用同一平方和，不需要真的画出高维图形。零向量的长度为零，非零向量的长度为正，并且 $\|cv\|_2=|c|\|v\|_2$。

本节点只表示标准实坐标几何中的 $2$-范数。现有“范数”节点讨论任意给定内积所诱导的更一般构造，因此二者保留不同作用域。

> 来源：Strang, 5th ed., §1.2, pp. 12-14。
