为什么只检查三项就能判定子空间

从唯一 tail 出发形成目标定义

本步骤唯一的 tail 是“向量空间”。因此读者已经知道：设 VVV 是 F\mathbb FF 上的向量空间，则 VVV 有加法、标量乘法、零向量与加法逆元，并满足全部向量空间公理；还知道

0v=0V,(−1)v=−v.0v=0_V, \qquad (-1)v=-v.0v=0V​,(−1)v=−v.

现在取一个子集 U⊆VU\subseteq VU⊆V。我们只使用从 VVV 继承的运算，并要判断：为了让 UUU 自己成为向量空间，哪些义务必须在 UUU 内重新检查，哪些规律可以直接从 VVV 继承？

先局部形成目标定义：如果 UUU 使用与 VVV 相同的零向量、加法和标量乘法，并且在这些继承运算下本身是向量空间，就称 UUU 是 VVV 的子空间。这是定义 1.33，也是本步骤要到达的 head。

直接重验全部公理很繁琐。我们要证明 Axler 结论 1.34：只检查零向量、加法封闭和标量乘法封闭就已充分，而且三项也都必要。

必要性：子空间一定满足三项条件

先假设 UUU 已按刚才的局部定义成为 VVV 的子空间。这是证明“当且仅当”的必要性方向，不是把结论偷当前提。

定义要求 UUU 与 VVV 使用相同的加法恒等元，所以

0V∈U.0_V\in U.0V​∈U.

因为 UUU 本身是向量空间，它的两种运算必须是函数

U×U⟶U,U\times U\longrightarrow U,U×U⟶U, F×U⟶U.\mathbb F\times U\longrightarrow U.F×U⟶U.

因此对任意 u,w∈Uu,w\in Uu,w∈U 与 a∈Fa\in\mathbb Fa∈F，都有

u+w∈U,au∈U.u+w\in U, \qquad au\in U.u+w∈U,au∈U.

三项条件都是必要的。

充分性：三项条件为何补齐全部公理

现在反过来假设 U⊆VU\subseteq VU⊆V 满足：

  1. 0V∈U0_V\in U0V​∈U ；
  2. 若 u,w∈Uu,w\in Uu,w∈U，则 u+w∈Uu+w\in Uu+w∈U ；
  3. 若 a∈Fa\in\mathbb Fa∈F 且 u∈Uu\in Uu∈U，则 au∈Uau\in Uau∈U。

我们不能先称 UUU 为子空间，必须从这些条件把定义中的每一项补齐。

第二、三项保证继承的加法和标量乘法不会把结果送出 UUU。第一项提供 UUU 所需的加法恒等元，因为对每个 u∈Uu\in Uu∈U，tail 已保证

其余公理不需要再构造。例如，对任意 u,w,z∈Uu,w,z\in Uu,w,z∈U，它们也是 VVV 中的向量，因此

于是 UUU 在继承运算下满足全部向量空间公理，按定义成为 VVV 的子空间。这完成了结论 1.34 的两个方向。

本步骤建立的范围

tail 中的向量空间公理负责所有能从环境 VVV 继承的恒等式；三项判据只负责保证零向量、加法结果、缩放结果和逆元没有离开 UUU。因此我们已经严格建立了子空间定义、结论 1.34 以及等价的线性组合判据。

本步骤没有要求 VVV 有限维，也没有引入基、张成或线性映射。它只回答“一个子集何时仍是完整的向量空间”。下一步才能研究多个子空间怎样合在一起，以及同一个向量的分量何时唯一。
