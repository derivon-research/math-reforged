保持范数等价于保持内积

前提的作用

等距映射前提已经给出保持内积与范数；伴随把该性质写成算子方程；“算子”保证定义域与陪域相同。有限维下的可逆性在本步骤内由等距性推出，不再把单射、满射或可逆性列为前提。

从内积到范数

若 TTT 保持内积，取两个输入相同立即得到

∥Tv∥2=⟨Tv,Tv⟩=⟨v,v⟩=∥v∥2.\|Tv\|^2=\langle Tv,Tv\rangle=\langle v,v\rangle=\|v\|^2.∥Tv∥2=⟨Tv,Tv⟩=⟨v,v⟩=∥v∥2.

从范数恢复内积

实空间使用极化恒等式

⟨u,v⟩=14(∥u+v∥2−∥u−v∥2),\langle u,v\rangle=\frac14(\|u+v\|^2-\|u-v\|^2),⟨u,v⟩=41​(∥u+v∥2−∥u−v∥2),

复空间在本书“第一变量线性”的约定下使用

⟨u,v⟩=14(∥u+v∥2−∥u−v∥2+i∥u+iv∥2−i∥u−iv∥2).\begin{aligned} \langle u,v\rangle=\frac14\bigl(& \|u+v\|^2-\|u-v\|^2\\ &+i\|u+iv\|^2-i\|u-iv\|^2 \bigr). \end{aligned}⟨u,v⟩=41​(​∥u+v∥2−∥u−v∥2+i∥u+iv∥2−i∥u−iv∥2).​

若 TTT 线性并保持所有向量的范数，把 Tu,TvTu,TvTu,Tv 代入相应恒等式，便得 ⟨Tu,Tv⟩=⟨u,v⟩\langle Tu,Tv\rangle=\langle u,v\rangle⟨Tu,Tv⟩=⟨u,v⟩。复公式中的 iii 号取决于内积线性变量的约定，不能直接照抄采用另一约定的版本。

改写成伴随方程

由伴随定义，

⟨Tu,Tv⟩=⟨u,T∗Tv⟩.\langle Tu,Tv\rangle=\langle u,T^*Tv\rangle.⟨Tu,Tv⟩=⟨u,T∗Tv⟩.

它对所有 u,vu,vu,v 等于 ⟨u,v⟩\langle u,v\rangle⟨u,v⟩，故 T∗T=IT^*T=IT∗T=I。这使 TTT 单射；在有限维同空间上，单射推出满射，于是 TTT 可逆并有

T−1=T∗.T^{-1}=T^*.T−1=T∗.

从而也有 TT∗=ITT^*=ITT∗=I。

规范正交基判据

保持内积显然把规范正交基送到规范正交组；同维时像组长度等于维数，所以是基。反向若 TTT 把一组规范正交基送到规范正交基，展开任意向量坐标即可证明保持内积。

结论边界

这些条件共同刻画有限维同空间上的幺正算子。不同维空间间的等距嵌入只有 T∗T=IVT^*T=I_VT∗T=IV​，未必有 TT∗=IWTT^*=I_WTT∗=IW​。
