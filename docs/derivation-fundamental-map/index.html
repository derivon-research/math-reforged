推出同维空间中的单射满射等价

若另有 dim⁡V=dim⁡W\dim V=\dim WdimV=dimW，则零空间为 {0}\{0\}{0} 当且仅当值域维数等于 dim⁡W\dim WdimW，也就当且仅当值域等于 WWW。因此同维有限空间间，单射与满射等价。

边界

定理要求 VVV 有限维；$W$ 是否有限维不必预先假设，因为值域由至多 dim⁡V\dim VdimV 个向量张成。无限维情形不能用简单的自然数减法照搬。
