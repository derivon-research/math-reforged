逆映射失效时保留什么

若 T:V→WT:V\to WT:V→W 不可逆，可能有两种障碍：零空间非零导致解不唯一，值域不等于 WWW 导致某些方程无解。伪逆 T†:W→VT^\dagger:W\to VT†:W→V 同时处理二者：只在 TTT 真正可逆的奇异方向上反演，其余方向取零。

两个投影恒等式

逐奇异方向计算得

T†T=P(null⁡T)⊥,T^\dagger T=P_{(\operatorname{null}T)^\perp},T†T=P(nullT)⊥​, TT†=Prange⁡T.TT^\dagger=P_{\operatorname{range}T}.TT†=PrangeT​.

因此若 TTT 可逆，这两个投影都是恒等算子，$T^\dagger=T^{-1}$；一般情形下伪逆不是左右逆。
