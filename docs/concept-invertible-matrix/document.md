# 可逆矩阵

存在逆矩阵的方阵称为可逆矩阵。对 $n\times n$ 矩阵 $A$，本章给出三个相互呼应的信号：

- 每个 $b\in\mathbb R^n$ 都有唯一解 $x=A^{-1}b$；
- $Ax=0$ 只有平凡解；
- $A$ 的 $n$ 个列向量线性无关，并能组合出整个 $\mathbb R^n$。

本节点只表示矩阵的可逆性，不等同于现有“可逆线性映射”节点。二者的坐标对应关系要在线性变换与基已经建立后另行推导。

> 来源：Strang, 5th ed., §1.3, pp. 24-27；§2.5, pp. 83-90 证明完整主元、齐次唯一零解与逆矩阵存在的对应。
