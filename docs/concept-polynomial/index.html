节点范围： 本节点只表示多项式及其运算。多项式的零点与因式判据已经拆成独立节点。

为什么算子理论需要多项式

多项式既可以作为函数求值，也可以把变量换成算子。后者会产生 T2,T3T^2,T^3T2,T3 等组合，是最小多项式、特征多项式和算子分解的语言。为避免把“公式相同”和“函数取值相同”混淆，本书把多项式理解为最终只有有限个非零项的系数序列。

实数域和复数域的差别
