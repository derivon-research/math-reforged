秩

矩阵真正传递了多少个独立方向

矩阵 AAA 的列空间是其所有列在 Fm\mathbb F^mFm 中的张成空间，列秩是这个空间的维数；行空间和行秩类似。一个并不显然但非常重要的事实是：

行秩 A=列秩 A.\text{行秩 }A=\text{列秩 }A.行秩 A=列秩 A.

共同的数称为 AAA 的秩，记作 rank⁡A\operatorname{rank}ArankA。

若 A=M(T)A=\mathcal M(T)A=M(T)，各列是基向量的像的坐标，它们张成 range⁡T\operatorname{range}TrangeT 的坐标版本，因此

rank⁡A=dim⁡range⁡T.\operatorname{rank}A=\dim\operatorname{range}T.rankA=dimrangeT.

这表明秩不是某个基下偶然出现的数字；换基虽改变矩阵元素，却不改变秩。

例子

A=(1224)A=\begin{pmatrix}1&2\\2&4\end{pmatrix}A=(12​24​)

的第二列是第一列的两倍，第二行也是第一行的两倍，所以行空间和列空间都只有一个独立方向，$\operatorname{rank}A=1$。它把平面压到一条线，而不是压到零点。

对 m×nm\times nm×n 矩阵，总有

0≤rank⁡A≤min⁡(m,n).0\le\operatorname{rank}A\le\min(m,n).0≤rankA≤min(m,n).

秩等于 nnn 表示对应映射在 nnn 维定义域上单射；秩等于 mmm 表示它满射到 mmm 维陪域。只有方阵时，“满列秩”和“满行秩”才是同一个最大值。

如何理解而不依赖消元术

行变换可以计算秩，但定义不是“阶梯形里非零行的数目”。真正不变量是值域维数；消元只是一种保持行空间或揭示独立主元的算法。这里的推导采用 Axler 的行列分解，从线性映射角度说明行秩为何必等于列秩。
