上三角化

节点范围： 本节点只表示上三角化。对角化要求存在特征向量基，是独立且更强的概念。

选择基是为了让结构可见

对算子 T∈L(V)T\in\mathcal L(V)T∈L(V)，矩阵依赖基。若某组基 v1,…,vnv_1,\ldots,v_nv1​,…,vn​ 使 M(T)\mathcal M(T)M(T) 在主对角线下方全为零，就说 TTT 可上三角化。这等价于

Tvk∈span⁡(v1,…,vk)Tv_k\in\operatorname{span}(v_1,\ldots,v_k)Tvk​∈span(v1​,…,vk​)

对每个 kkk 成立，即基的前缀形成一条 $T$-不变子空间链。

若某组基使矩阵只有对角元可能非零，就说 TTT 可对角化。此时

Tvk=λkvk,Tv_k=\lambda_kv_k,Tvk​=λk​vk​,

所以这组基全由特征向量组成。反过来，任何特征向量基都会给出对角矩阵。因此

T 可对角化⟺V 有一组由 T 的特征向量组成的基.T\text{ 可对角化} \Longleftrightarrow V\text{ 有一组由 }T\text{ 的特征向量组成的基}.T 可对角化⟺V 有一组由 T 的特征向量组成的基.

两者强弱不同

对角矩阵必上三角，但上三角矩阵未必可对角化。例如

A=(1101)A=\begin{pmatrix}1&1\\0&1\end{pmatrix}A=(10​11​)

已经上三角，却只有一维特征空间，不能提供二维特征向量基。

有限维复空间上的每个算子都可上三角化，因为每个非零复空间上的算子都有特征值，可以递归构造不变子空间链。实空间上不一定，例如非平凡二维旋转没有实特征值。

最小多项式判据

算子可对角化当且仅当其最小多项式能分解为互不相同的一次因子：

qT(z)=(z−λ1)⋯(z−λm).q_T(z)=(z-\lambda_1)\cdots(z-\lambda_m).qT​(z)=(z−λ1​)⋯(z−λm​).

重复因子代表某个方向需要广义特征向量链，正是不可对角化的障碍。

不要混淆的说法

“矩阵是上三角/对角”依赖当前基；“算子可上三角化/可对角化”是存在某组基的性质。数域也属于条件的一部分。
