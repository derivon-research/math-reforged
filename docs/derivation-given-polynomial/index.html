多项式算术与零点理论

为什么数域是这里的真实前提

多项式系数和零点都属于固定数域 F\mathbb FF。带余除法要除以非零首项系数，因式分解的形状又取决于 F\mathbb FF 是 R\mathbb RR 还是 C\mathbb CC。本步骤把这些差异完整展开。

从有限系数到次数

多项式只有有限个非零系数，故加法与乘法仍只产生有限个非零系数。若 p,qp,qp,q 非零，域中没有零因子，所以最高次项乘积非零，得到

deg⁡(pq)=deg⁡p+deg⁡q.\deg(pq)=\deg p+\deg q.deg(pq)=degp+degq.

这条次数公式是零点个数归纳法的基础。

数域决定分解结论

代数基本定理作为外部代数事实输入：每个非常数复多项式有复零点。反复应用因式定理便得到完全一次分解。实多项式若有非实零点 λ\lambdaλ，共轭 λ‾\overline\lambdaλ 也为零点，二者组合成实二次因子；所以实多项式分解为实一次与不可约二次因子。

结论与限制

我们得到多项式的次数、零点、带余除法和实/复分解理论。代数基本定理不是由数域公理在本页证明的，应明确视为教材采用的重要定理，而不是隐藏假设。
