对偶空间

节点范围： 本节点只表示对偶空间。对偶映射是以两个对偶空间和一个线性映射为前提的独立节点。

用线性测量认识向量

从 VVV 到标量域的线性映射称为线性泛函。全体线性泛函构成对偶空间

V′=L(V,F).V'=\mathcal L(V,\mathbb F).V′=L(V,F).

与其把泛函只看成“行向量”，更有用的理解是：它对向量做一次保持线性组合的标量测量。有限维时，这些测量足以区分任意两个不同向量。

对偶基

若 v1,…,vnv_1,\ldots,v_nv1​,…,vn​ 是 VVV 的基，则存在唯一泛函 φ1,…,φn\varphi_1,\ldots,\varphi_nφ1​,…,φn​ 满足

φj(vk)=δjk.\varphi_j(v_k)=\delta_{jk}.φj​(vk​)=δjk​.

它们构成 V′V'V′ 的对偶基。若 v=a1v1+⋯+anvnv=a_1v_1+\cdots+a_nv_nv=a1​v1​+⋯+an​vn​，则

φj(v)=aj.\varphi_j(v)=a_j.φj​(v)=aj​.

所以对偶基逐个读取坐标。有限维时 dim⁡V′=dim⁡V\dim V'=\dim VdimV′=dimV，但 VVV 与 V′V'V′ 的同构通常依赖基；没有额外结构时不存在自然的“向量等于泛函”。内积稍后会提供一种自然对应。

对偶映射为何反向

给定 T∈L(V,W)T\in\mathcal L(V,W)T∈L(V,W)，定义

T′:W′→V′,T′(φ)=φ∘T.T':W'\to V',\qquad T'(\varphi)=\varphi\circ T.T′:W′→V′,T′(φ)=φ∘T.

一个原本测量 WWW 中向量的泛函，先让输入经过 TTT，就变成测量 VVV 中向量的泛函，因此方向反转。复合也反序：

(ST)′=T′S′.(ST)'=T'S'.(ST)′=T′S′.

在对偶基下，$T'$ 的矩阵是 TTT 的矩阵的转置，而不是共轭转置；共轭转置属于内积定义的伴随，二者不要混淆。

零化子

对子空间 U⊆VU\subseteq VU⊆V，其零化子

U0={φ∈V′:φ(u)=0 对所有 u∈U}U^0=\{\varphi\in V':\varphi(u)=0\text{ 对所有 }u\in U\}U0={φ∈V′:φ(u)=0 对所有 u∈U}

收集所有看不见 UUU 的线性测量。有限维时 dim⁡U0=dim⁡V−dim⁡U\dim U^0=\dim V-\dim UdimU0=dimV−dimU，它会精确描述对偶映射的零空间和值域。
