# 点积

对实坐标向量 $v=(v_1,\ldots,v_n)$ 与 $w=(w_1,\ldots,w_n)$，点积是标量

$$
v\mathbin{\cdot}w=v_1w_1+\cdots+v_nw_n.
$$

它先逐坐标相乘，再把结果相加，因此输入是两个同维向量，输出是一个实数。点积满足交换律、对向量加法的分配律和对数乘的齐次性。它可以表示力矩、价格与数量的总收入，也为欧几里得长度和正交提供计算入口。

本节点只表示 $\mathbb R^n$ 的标准点积，不等同于抽象向量空间上任意选择的内积。

> 来源：Strang, *Introduction to Linear Algebra*, 5th ed., §1.2, pp. 11-21；定义与应用见 pp. 11-12，运算规则见 p. 20。
