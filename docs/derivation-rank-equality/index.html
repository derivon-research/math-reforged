行秩等于列秩

为什么需要证明

列秩容易理解为对应线性映射的值域维数，行秩则来自矩阵的行向量。两者定义在不同的坐标空间中，相等并非定义，而是需要结构性论证。

行列分解

设 AAA 是 m×nm\times nm×n 矩阵，列秩为 ccc。从 AAA 的列中选出基 A⋅,k1,…,A⋅,kcA_{\cdot,k_1},\ldots,A_{\cdot,k_c}A⋅,k1​​,…,A⋅,kc​​，把它们组成 m×cm\times cm×c 矩阵 CCC。每一列 A⋅,kA_{\cdot,k}A⋅,k​ 都可唯一写成这些基列的线性组合；把系数组成 c×nc\times nc×n 矩阵 RRR，就有

A=CR.A=CR.A=CR.

RRR 中对应 k1,…,kck_1,\ldots,k_ck1​,…,kc​ 的那些列形成 c×cc\times cc×c 恒等矩阵，因此 RRR 的 ccc 行线性无关。

先得到行秩不超过列秩

AAA 的每一行都是 CCC 的相应一行乘 RRR，所以它是 RRR 的各行的线性组合。故

rowrank⁡A≤c=columnrank⁡A.\operatorname{rowrank}A\le c=\operatorname{columnrank}A.rowrankA≤c=columnrankA.

对转置重复同一论证

AtA^tAt 的行秩是 AAA 的列秩，$A^t$ 的列秩是 AAA 的行秩。把刚得的不等式应用于 AtA^tAt，有

columnrank⁡A≤rowrank⁡A.\operatorname{columnrank}A\le\operatorname{rowrank}A.columnrankA≤rowrankA.

两边合并即得行秩等于列秩。

一个快速核对

对 A=(1224)A=\begin{pmatrix}1&2\\2&4\end{pmatrix}A=(12​24​)，可取 C=(1,2)^t$、$R=(1,2)，于是 A=CRA=CRA=CR。CCC 有一个独立列，$R$ 有一个独立行，两种秩都为 111。

结论

共同的维数称为矩阵的秩。证明依赖有限维基和矩阵表示，不是把“行”和“列”在记号上强行对称。
