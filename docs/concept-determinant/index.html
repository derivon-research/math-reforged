核心性质

复合在最高次交错型上的缩放依次相乘，所以

det⁡(ST)=det⁡S det⁡T.\det(ST)=\det S\,\det T.det(ST)=detSdetT.

若 TTT 不可逆，基的像线性相关，交错型取值为零，故 \det T=0$；若 $T 可逆，由 TT−1=ITT^{-1}=ITT−1=I 和乘法性得 det⁡T≠0\det T\ne0detT=0。所以

T 可逆⟺det⁡T≠0.T\text{ 可逆}\Longleftrightarrow\det T\ne0.T 可逆⟺detT=0.

相似算子行列式相同。上三角矩阵的行列式是对角元之积；复空间上也等于按代数重数计的特征值之积。

几何解释与限制

∣det⁡T∣|\det T|∣detT∣ 是 nnn 维体积缩放倍数，实数情形的符号记录定向是否翻转。行列式只定义于同一有限维空间上的算子或方阵；非方矩阵没有通常意义的单个行列式。
