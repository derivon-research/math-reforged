维数

节点范围： 本节点只表示有限维向量空间的维数。有限维性已经拆成独立节点；无限维在下文仅作为定义边界。

“基的长度”为什么不能立刻拿来定义

一个空间可能有许多组不同的基。若我们还不知道这些基长度相同，就贸然说“维数是某一组基的长度”，答案可能随所选的基改变，这个定义便没有确定含义。

因此逻辑顺序必须是：

  1. 先说明空间里存在有限张成组；
  2. 再从有限张成组削减出基；
  3. 用替换法证明任意两组基等长；
  4. 最后才把这个共同长度命名为维数。

前一条推导已经完成了第 2、3 步。尤其是，基等长不是维数定义后的显然事实，而是让维数能够被定义的前提。

三个正式定义

设 VVV 是数域 F\mathbb FF 上的向量空间。

若 VVV 中存在某个有限向量组张成 VVV ，就称 VVV 是有限维向量空间。这里并没有预先规定张成组必须线性无关；前面的削减定理保证可以从中删去冗余项，得到一组基。

若不存在任何有限向量组张成 VVV ，就称 VVV 是无限维向量空间。这只是对“存在有限张成组”的否定。

对有限维向量空间 VVV ，任取它的一组基。所有基已经被证明长度相同，因此把这个共同长度称为 VVV 的维数，记作

dim⁡V.\dim V.dimV.

标量域 F\mathbb FF 是定义的一部分。同一个集合配上不同的标量域，允许的线性组合不同，基与维数也可能改变。

零空间为什么维数是零

空向量组的张成空间是 {0}\{0\}{0}，并且空向量组线性无关，所以它是零向量空间的一组基。空组长度为 000，因此

dim⁡{0}=0.\dim\{0\}=0.dim{0}=0.

零空间含有一个向量，却有维数零。这再次说明维数不是“空间中有多少个元素”，而是基含有多少项。

同一个集合换标量域，维数会改变

把 C\mathbb CC 看成复向量空间时，单向量组 (1)(1)(1) 是一组基：每个 z∈Cz\in\mathbb Cz∈C 都能唯一写成

z=z⋅1,z=z\cdot1,z=z⋅1,

所以

dim⁡CC=1.\dim_{\mathbb C}\mathbb C=1.dimC​C=1.

把同一个集合 C\mathbb CC 看成实向量空间时，允许的系数只能是实数。此时 (1,i)(1,i)(1,i) 是一组基，因为每个 z=x+yiz=x+yiz=x+yi 都能由唯一的实数 x,yx,yx,y 写成

z=x⋅1+y⋅i.z=x\cdot1+y\cdot i.z=x⋅1+y⋅i.

因此

dim⁡RC=2.\dim_{\mathbb R}\mathbb C=2.dimR​C=2.

这里向量集合和向量加法都没有改变；改变的是允许作为系数的数域。忽略标量域，就无法正确谈论维数。

子空间为什么不会比环境空间维数更大

设 VVV 有限维， UUU 是 VVV 的子空间。先要说明 UUU 自己也是有限维的。

若 U={0}U=\{0\}U={0} ，结论已经知道。否则在 UUU 中选一个非零向量 u1u_1u1​。只要当前组还不张成 UUU，就从 UUU 中再选一个不属于当前 span 的向量并加入。每次加入后，所得组仍线性无关；否则线性相关性引理会指出某个 uku_kuk​ 处在 u1,…,uk−1u_1,\ldots,u_{k-1}u1​,…,uk−1​ 的 span 中，与选取 uku_kuk​ 时的条件矛盾。

这个过程不可能选出比 VVV 的某个有限基更长的线性无关组，因为长度比较定理说：线性无关组的长度不超过张成 VVV 的基的长度。因此过程会在有限步内停止，停止时所得组线性无关且张成 UUU，也就是 UUU 的基。

现在把 UUU 的基看作 VVV 中的线性无关组，把 VVV 的基看作 VVV 中的张成组。再用一次长度比较，得到

dim⁡U≤dim⁡V.\dim U\le\dim V.dimU≤dimV.

这就是子空间维数定理 2.37 的实质理由：子空间中的无关方向仍是环境空间中的无关方向，所以不可能多于环境空间的一组生成材料。

恰当长度为什么只需再查一个条件

设 dim⁡V=n\dim V=ndimV=n。

长度为 nnn 且线性无关。 若 v1,…,vnv_1,\ldots,v_nv1​,…,vn​ 线性无关，扩充定理允许把它们保留下来并添加若干向量，得到 VVV 的一组基。但 VVV 的每组基长度都是 nnn ；若真添加了向量，新基就会超过 nnn 项，矛盾。因此无需添加，原组已经张成 VVV，所以是基。这是 2.38。

长度为 nnn 且张成 VVV。 若 v1,…,vnv_1,\ldots,v_nv1​,…,vn​ 张成 VVV，削减定理允许删除冗余项，得到 VVV 的一组基。但每组基长度都是 nnn ；若真删除了向量，所得基就会少于 nnn 项，矛盾。因此无需删除，原组已经线性无关，所以是基。这是 2.42。

长度单独不够。在 F2\mathbb F^2F2 中，向量组

e1, 2e1e_1,\ 2e_1e1​, 2e1​

有两项，而 dim⁡F2=2\dim\mathbb F^2=2dimF2=2。但是

2(e1)−1(2e1)=02(e_1)-1(2e_1)=02(e1​)−1(2e1​)=0

是一条非平凡关系，并且 e2e_2e2​ 不在它的张成空间中。所以它既不线性无关，也不张成 F2\mathbb F^2F2，当然不是基。

正确的判据是“恰当长度 + 线性无关”或“恰当长度 + 张成”，而不是只数向量个数。

等维子空间为什么只能是整个空间

设 UUU 是有限维空间 VVV 的子空间，并且

dim⁡U=dim⁡V=n.\dim U=\dim V=n.dimU=dimV=n.

取 UUU 的一组基 u1,…,unu_1,\ldots,u_nu1​,…,un​。它在 VVV 中仍线性无关，长度又恰好是 dim⁡V\dim VdimV，所以由 2.38 可知它也是 VVV 的基。于是它既张成 UUU 又张成 VVV：

U=span⁡(u1,…,un)=V.U=\operatorname{span}(u_1,\ldots,u_n)=V.U=span(u1​,…,un​)=V.

因此

U=V.U=V.U=V.

这就是 2.39。条件“ UUU 是 VVV 的子空间”不可省略；维数相同的两个无关空间并不会自动成为同一个集合。

无限维只否定有限张成组

令 P(F)\mathcal P(\mathbb F)P(F) 表示所有系数在 F\mathbb FF 中的多项式组成的向量空间，运算是通常的多项式加法与标量乘法。

任取其中一个有限多项式组。因为多项式只有有限多个，可以选一个整数 ddd ，使组中每个非零多项式的次数都不超过 ddd。它们的任意线性组合次数仍不超过 ddd，所以多项式

zd+1z^{d+1}zd+1

不在这个有限组的张成空间中。若所取的组为空或全由零多项式组成，它显然连常数多项式 111 都不能张成。

因此没有任何有限多项式组能够张成 P(F)\mathcal P(\mathbb F)P(F)，所以它是无限维向量空间。这就是例 2.14 的次数上界论证。

“无限维”在这里仅表示“不存在有限张成组”。它并不等于我们已经构造出某个无穷长的基；无穷基是否存在、怎样定义与怎样构造，是另一个需要额外论证的问题，本页没有使用它。

维数现在能安全地告诉我们什么

维数是有限维空间任一组基的共同长度。它依赖标量域，不依赖具体选择哪一组基；它约束线性无关组与张成组的长度，并让我们在已知恰当长度时只需再检查“无关”或“张成”中的一个条件。

这套结论也适用于子空间：子空间维数不超过环境空间维数，等号成立时子空间就是整个空间。所有这些判断都建立在前一页已经证明的削减、替换、扩充与基等长之上，没有使用矩阵、行列式，也没有纳入子空间之和的维数公式。
