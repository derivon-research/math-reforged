为什么零空间和值域一定是子空间

现在真正需要建立什么

设 V,WV,WV,W 是同一数域 F\mathbb FF 上的向量空间，并且 T∈L(V,W)T\in\mathcal L(V,W)T∈L(V,W)。我们想从一个线性映射中找出两个有用的集合：

  • 在定义域中，收集所有被送到 0W0_W0W​ 的输入；
  • 在陪域中，收集所有确实能由某个输入产生的输出。

因此现在定义

null⁡T={v∈V:Tv=0W}.\operatorname{null}T=\{v\in V:Tv=0_W\}.nullT={v∈V:Tv=0W​}.

在箭头的另一端，定义

range⁡T={Tv:v∈V}.\operatorname{range}T=\{Tv:v\in V\}.rangeT={Tv:v∈V}.

定义只说明集合中有什么，并没有自动证明它们具有线性结构。本步骤要建立的 正是 Axler 的结论 3.13 与 3.18：

null⁡T≤V,range⁡T≤W.\operatorname{null}T\le V, \qquad \operatorname{range}T\le W.nullT≤V,rangeT≤W.

这里 U≤VU\le VU≤V 表示 UUU 是 VVV 的子空间。证明不假设 TTT 单射、满射 或可逆，也不要求 V,WV,WV,W 有限维。

两个 tail 前提各自承担什么工作

线性映射前提提供

T(u+v)=Tu+Tv.T(u+v)=Tu+Tv.T(u+v)=Tu+Tv.

以及

T(λu)=λTu,T(\lambda u)=\lambda Tu,T(λu)=λTu,

以及由线性性推出的 T(0V)=0WT(0_V)=0_WT(0V​)=0W​。这些等式让我们把输入端的加法与 数乘搬到输出端。

子空间前提提供判定目标。对一个子集 U⊆VU\subseteq VU⊆V，只需证明：

  1. 0V∈U0_V\in U0V​∈U ；
  2. UUU 对加法封闭；
  3. UUU 对标量乘法封闭。

所以证明计划是：先确认两个集合分别位于哪个环境空间，再逐项完成这三项检查。

待证集合 环境空间 线性性要完成的关键转换
null⁡T\operatorname{null}TnullT 定义域 VVV 已知像为 0W0_W0W​，推出输入组合的像仍为 0W0_W0W​
range⁡T\operatorname{range}TrangeT 陪域 WWW 先给输出选择原像，再组合这些原像

第二行的“选择原像”是值域证明最容易漏掉的一步。

先用一个二维映射看清目标

贯穿下面证明的例子是

T:R2→R2,T(x,y)=(x+y,0).T:\mathbb R^2\to\mathbb R^2, \qquad T(x,y)=(x+y,0).T:R2→R2,T(x,y)=(x+y,0).

求零空间就是解 T(x,y)=(0,0)T(x,y)=(0,0)T(x,y)=(0,0)，所以

null⁡T={(t,−t):t∈R}.\operatorname{null}T=\{(t,-t):t\in\mathbb R\}.nullT={(t,−t):t∈R}.

求值域则让 (x,y)(x,y)(x,y) 遍历 R2\mathbb R^2R2。第一坐标 x+yx+yx+y 可取任意 实数，第二坐标始终为 000，所以

range⁡T={(s,0):s∈R}.\operatorname{range}T=\{(s,0):s\in\mathbb R\}.rangeT={(s,0):s∈R}.

一条过原点的斜线与一条横轴看起来确实是子空间，但图像不能证明任意线性映射 都如此。下面完成一般论证。

零空间为何是定义域的子空间

按照定义，零空间中的元素都属于 VVV，所以

null⁡T⊆V.\operatorname{null}T\subseteq V.nullT⊆V.

接下来应用子空间判据。

零向量在零空间中

最自然的候选是定义域的零向量 0V0_V0V​。线性性给出

T(0V)=0W.T(0_V)=0_W.T(0V​)=0W​.

这正好满足零空间的条件，因此

0V∈null⁡T.0_V\in\operatorname{null}T.0V​∈nullT.

下标提醒我们：等式左边输入的是 VVV 中的零向量，右边得到的是 WWW 中 的零向量。即使底层记号都写成 000，它们在论证中承担不同的类型角色。

对加法封闭

任取 u,v∈null⁡Tu,v\in\operatorname{null}Tu,v∈nullT。展开定义就是 Tu=0WTu=0_WTu=0W​ 且 Tv=0WTv=0_WTv=0W​。为了检查 u+vu+vu+v，使用可加性：

T(u+v)=Tu+Tv=0W+0W=0W.\begin{aligned} T(u+v) &=Tu+Tv\\ &=0_W+0_W\\ &=0_W. \end{aligned}T(u+v)​=Tu+Tv=0W​+0W​=0W​.​

第一行搬运加法，第二行才代入零空间条件。因此

u+v∈null⁡T.u+v\in\operatorname{null}T.u+v∈nullT.

在二维例子中， (s,−s)+(t,−t)=(s+t,−s−t)(s,-s)+(t,-t)=(s+t,-s-t)(s,−s)+(t,−t)=(s+t,−s−t) ，仍满足两个坐标之和 为零。

对标量乘法封闭

任取 u∈null⁡Tu\in\operatorname{null}Tu∈nullT 和 λ∈F\lambda\in\mathbb Fλ∈F。齐次性给出

T(λu)=λTu=λ0W=0W.\begin{aligned} T(\lambda u) &=\lambda Tu\\ &=\lambda 0_W\\ &=0_W. \end{aligned}T(λu)​=λTu=λ0W​=0W​.​

所以 λu∈null⁡T\lambda u\in\operatorname{null}Tλu∈nullT。三项检查全部完成，由子空间 判据，

null⁡T 是 V 的子空间.\boxed{\operatorname{null}T\text{ 是 }V\text{ 的子空间}.}nullT 是 V 的子空间.​

这就是教材结论 3.13。

为什么一般函数的零点集不能照搬

上面的证明真正使用了线性性。普通函数

f:R→R,f(x)=x2−1f:\mathbb R\to\mathbb R, \qquad f(x)=x^2-1f:R→R,f(x)=x2−1

的零点集合是 {−1,1}\{-1,1\}{−1,1}。它不含 000，而且 1+1=21+1=21+1=2 也不在其中， 所以不是 R\mathbb RR 的子空间。失败的根源是不能把 f(u+v)f(u+v)f(u+v) 改写成 f(u)+f(v)f(u)+f(v)f(u)+f(v)。

正确结论是“线性映射的零空间是子空间”，而不是“任何函数的零点集合 都是子空间”。

值域为何是陪域的子空间

按照定义，每个 TvTvTv 都属于 WWW，所以

range⁡T⊆W.\operatorname{range}T\subseteq W.rangeT⊆W.

这次要在陪域 WWW 中应用判据。

零向量在值域中

等式 T(0V)=0WT(0_V)=0_WT(0V​)=0W​ 不仅给出一个零，还给出了一个具体原像：输入 0V0_V0V​ 会产生输出 0W0_W0W​。因此

0W∈range⁡T.0_W\in\operatorname{range}T.0W​∈rangeT.

对加法封闭

任取 w1,w2∈range⁡Tw_1,w_2\in\operatorname{range}Tw1​,w2​∈rangeT。值域定义中的存在量词告诉 我们，可以分别选择 v1,v2∈Vv_1,v_2\in Vv1​,v2​∈V，使得

Tv1=w1,Tv2=w2.Tv_1=w_1, \qquad Tv_2=w_2.Tv1​=w1​,Tv2​=w2​.

要证明 w1+w2w_1+w_2w1​+w2​ 可达，自然尝试把原像相加。线性性给出

T(v1+v2)=Tv1+Tv2=w1+w2.\begin{aligned} T(v_1+v_2) &=Tv_1+Tv_2\\ &=w_1+w_2. \end{aligned}T(v1​+v2​)​=Tv1​+Tv2​=w1​+w2​.​

这个公式明确提供了原像： w1+w2w_1+w_2w1​+w2​ 的一个原像就是 v1+v2v_1+v_2v1​+v2​。因此

w1+w2∈range⁡T.w_1+w_2\in\operatorname{range}T.w1​+w2​∈rangeT.

在二维例子中， (r,0)(r,0)(r,0) 与 (s,0)(s,0)(s,0) 可分别选原像 (r,0)(r,0)(r,0) 与 (s,0)(s,0)(s,0) ； 两原像之和被送到 (r+s,0)(r+s,0)(r+s,0)。

对标量乘法封闭

任取 w∈range⁡Tw\in\operatorname{range}Tw∈rangeT 与 λ∈F\lambda\in\mathbb Fλ∈F。先展开 值域定义：存在 v∈Vv\in Vv∈V 使 Tv=wTv=wTv=w。缩放这个原像即可：

T(λv)=λTv=λw.\begin{aligned} T(\lambda v) &=\lambda Tv\\ &=\lambda w. \end{aligned}T(λv)​=λTv=λw.​

所以 λv\lambda vλv 是 λw\lambda wλw 的一个原像，进而

λw∈range⁡T.\lambda w\in\operatorname{range}T.λw∈rangeT.

三项检查完成，由子空间判据，

range⁡T 是 W 的子空间.\boxed{\operatorname{range}T\text{ 是 }W\text{ 的子空间}.}rangeT 是 W 的子空间.​

这就是教材结论 3.18。

相似的判据，不同的关键动作

两个证明都使用线性性和子空间判据，却不能机械替换名词：

  • 对零空间，我们从 Tu=Tv=0WTu=Tv=0_WTu=Tv=0W​ 出发，证明输入组合仍被送到 0W0_W0W​ ；
  • 对值域，我们从“输出存在原像”出发，构造原像的和与标量倍。

尤其不能省略值域定义中的存在量词。仅仅说“值域对加法封闭”是在重复 待证结论；必须展示 v1+v2v_1+v_2v1​+v2​ 这个具体原像。

这一步证明了什么

我们已经从“线性映射”与“子空间”两个 tail 完整推出

null⁡T≤V,range⁡T≤W.\operatorname{null}T\le V, \qquad \operatorname{range}T\le W.nullT≤V,rangeT≤W.

本步骤没有假设或证明零空间和值域的维数关系，也没有证明 TTT 单射或满射。 它只建立后续论证需要的结构事实：这两个集合确实是子空间，所以可以讨论它们 的基与维数。

从解方程的角度看，值域将用于判断 Tv=wTv=wTv=w 是否有解，零空间将描述不同解 之间能够相差的方向。这是本结论打开的下一道问题，而不是本超边额外承担的证明。
