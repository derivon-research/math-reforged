节点范围： 本节点只表示定义域与陪域相同的线性映射。不变子空间是以算子和子空间为前提的独立节点。

为什么把同空间映射单独命名

线性映射 T:V→WT:V\to WT:V→W 一般只能作用一次；若定义域与陪域相同，就能反复作用、相加、复合并代入多项式。这样的映射

T∈L(V,V)=L(V)T\in\mathcal L(V,V)=\mathcal L(V)T∈L(V,V)=L(V)

称为 VVV 上的算子。

为什么不变子空间有用

若能把 VVV 分成若干 $T$-不变子空间的直和，就能分别研究各限制算子再拼回整体。上三角化、谱定理、广义特征空间和若当型都围绕这种降维策略展开。
