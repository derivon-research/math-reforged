商空间

把某些方向视为“没有差别”

设 UUU 是 VVV 的子空间。若我们只关心向量在 UUU 方向之外的差异，就应把相差一个 UUU 中向量的两个向量视为相同。对 v∈Vv\in Vv∈V，定义陪集

v+U={v+u:u∈U}.v+U=\{v+u:u\in U\}.v+U={v+u:u∈U}.

所有陪集构成商空间

V/U={v+U:v∈V}.V/U=\{v+U:v\in V\}.V/U={v+U:v∈V}.

它的元素不是单个向量，而是整类彼此相差 UUU 中向量的向量。

何时两个代表元表示同一元素

v+U=w+U⟺v−w∈U.v+U=w+U\quad\Longleftrightarrow\quad v-w\in U.v+U=w+U⟺v−w∈U.

因此代表元不唯一。运算定义为

(v+U)+(w+U)=(v+w)+U,(v+U)+(w+U)=(v+w)+U,(v+U)+(w+U)=(v+w)+U, a(v+U)=av+U.a(v+U)=av+U.a(v+U)=av+U.

必须证明这些定义不依赖代表元：若 v−v′∈Uv-v'\in Uv−v′∈U 且 w−w′∈Uw-w'\in Uw−w′∈U，则 $(v+w)-(v'+w')\in U$；标量倍同理。这一步叫“良定义”，不能因为公式看起来自然就省略。

几何例子

在 R2\mathbb R^2R2 中令 UUU 为横轴。每个陪集是一条水平线；两点属于同一陪集当且仅当纵坐标相同。因此 R2/U\mathbb R^2/UR2/U 只保留一个纵向自由度，并与 R\mathbb RR 同构。

若 VVV 有限维，则

dim⁡(V/U)=dim⁡V−dim⁡U.\dim(V/U)=\dim V-\dim U.dim(V/U)=dimV−dimU.

可取 UUU 的基并扩充为 VVV 的基；新增基向量对应的陪集恰好构成 V/UV/UV/U 的基。
