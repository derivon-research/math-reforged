为什么“保持加法与缩放”就是线性

我们想保留向量空间的什么

向量空间把许多不同对象统一起来：坐标向量、多项式、函数和序列看起来完全不同，但都可以相加，也都可以乘标量。若要在两个向量空间之间搬运信息，一个自然愿望是：映射之后，这两种基本操作仍然有效。

设 T:V→WT:V\to WT:V→W 是一个函数。我们暂时不知道应该怎样定义“线性”，只提出一个结构保持问题：

在 VVV 中先把若干向量缩放、相加，与先把每个向量送到 WWW 再做同样组合，什么时候会得到同一个结果？

这个问题说明了为什么定义会包含可加性与齐次性，而不是任意挑选两条公式。

两条基本要求

向量空间提供两种运算，所以逐一要求 TTT 保持它们。

保持加法：

T(u+v)=Tu+Tv.T(u+v)=Tu+Tv.T(u+v)=Tu+Tv.

这表示把两个输入合并后处理，不会与分别处理后再合并产生差异。

保持标量乘法：

T(λv)=λTv.T(\lambda v)=\lambda Tv.T(λv)=λTv.

这表示输入放大、缩小或反向多少倍，输出也做同样的缩放。

满足这两条要求的函数，就称为从 VVV 到 WWW 的线性映射。注意 VVV 与 WWW 可以是不同的向量空间；线性映射并不要求输入与输出长得一样。

为什么两条要求能控制所有线性组合

先看两个带系数的向量。对任意 a,b∈Fa,b\in\mathbb Fa,b∈F 和 u,v∈Vu,v\in Vu,v∈V，先用可加性把和拆开，再用齐次性把系数移到映射外：

T(au+bv)=T(au)+T(bv)=aTu+bTv.\begin{aligned} T(au+bv) &=T(au)+T(bv)\\ &=aTu+bTv. \end{aligned}T(au+bv)​=T(au)+T(bv)=aTu+bTv.​

第一步使用可加性，第二步使用齐次性；公式中的每一行都正好对应定义中的一条要求。

这已经得到最常用的合并形式。若有更多项，可重复使用同一个想法。例如三项时，先把前两项看成一个整体：

x=a1v1+a2v2.x=a_1v_1+a_2v_2.x=a1​v1​+a2​v2​.

可加性先把这个整体与第三项拆开，再把已经证明的两项公式用在 xxx 上：

T(x+a3v3)=Tx+T(a3v3).T(x+a_3v_3)=Tx+T(a_3v_3).T(x+a3​v3​)=Tx+T(a3​v3​).

其中 Tx=a1Tv1+a2Tv2Tx=a_1Tv_1+a_2Tv_2Tx=a1​Tv1​+a2​Tv2​，第三项也可直接用齐次性拆开。也就是说，三项的输出仍是三个对应输出之和。继续归纳，就得到任意有限线性组合的公式：

T(a1v1+⋯+amvm)=a1Tv1+⋯+amTvm.\begin{aligned} &T(a_1v_1+\cdots+a_mv_m)\\ &\qquad=a_1Tv_1+\cdots+a_mTv_m. \end{aligned}​T(a1​v1​+⋯+am​vm​)=a1​Tv1​+⋯+am​Tvm​.​

所以“保持加法与缩放”并非只控制两个特殊动作；它们共同保证 TTT 保持向量空间中所有有限的组合方式。

一个立刻得到的必要条件

令标量 λ=0\lambda=0λ=0。齐次性给出

T0=T(0v)=0Tv=0.T0=T(0v)=0Tv=0.T0=T(0v)=0Tv=0.

因此线性映射一定把原点映到原点。这是一个快速排除法：例如 f(x)=x+3f(x)=x+3f(x)=x+3 满足普通语言中的“直线函数”印象，却有 f(0)=3f(0)=3f(0)=3，所以它不是线性代数意义下的线性映射。

但 T0=0T0=0T0=0 只是必要条件，不是完整判据。函数 f(x)=x2f(x)=x^2f(x)=x2 也把 000 映到 000，却不保持加法：

f(1+1)=4≠2=f(1)+f(1).f(1+1)=4\ne2=f(1)+f(1).f(1+1)=4=2=f(1)+f(1).

真正的线性仍需对所有输入同时满足两条定义。

为什么这个定义能覆盖看似不同的例子

考虑微分映射 Dp=p′D p=p'Dp=p′。微积分中已经知道

(f+g)′=f′+g′,(λf)′=λf′.(f+g)'=f'+g',\qquad (\lambda f)'=\lambda f'.(f+g)′=f′+g′,(λf)′=λf′.

这两条熟悉规则恰好就是可加性与齐次性，因此微分是线性映射。积分、序列的后向移位、固定乘以某个多项式也以同样理由成为线性映射。

这个例子揭示了定义的作用：它不关心对象是箭头还是函数，只检查处理过程是否尊重向量空间结构。

几何直觉的边界

在 R2\mathbb R^2R2 中，线性映射会把直线网格送成仍由直线组成的网格，并保持平行关系；但它可以把平面压到一条线，甚至把所有向量都送到 000。因此线性不等于保持角度、长度、面积或可逆性。

“保持结构”比“保持形状”更准确。投影会压扁图形，却仍满足

T(au+bv)=aTu+bTv.T(au+bv)=aTu+bTv.T(au+bv)=aTu+bTv.

结论与下一步

线性映射就是保持向量加法与标量乘法的函数。之所以选择这两条公理，是因为它们恰好推出对所有有限线性组合的保持性；这让复杂输入能够被拆开处理，再无损地组合输出。

有了这个定义，下一步可以问两个非常具体的问题：哪些输入被送到 000，以及哪些输出能够被映射得到。它们分别形成零空间和值域，并进一步揭示一个线性映射丢失了多少信息、覆盖了多少目标空间。
