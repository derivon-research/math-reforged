最高次交错型上的缩放定义行列式

两个前提怎样锁定一个标量

交错型前提说明 nnn 维空间的最高次交错型空间是一维；算子把每个输入 vjv_jvj​ 送到 TvjTv_jTvj​，从而在这个一维空间上诱导作用。它只能是乘某个标量。

固定非零最高次交错型 ω\omegaω。定义

(T⋅ω)(v1,…,vn)=ω(Tv1,…,Tvn).(T\cdot\omega)(v_1,\ldots,v_n) =\omega(Tv_1,\ldots,Tv_n).(T⋅ω)(v1​,…,vn​)=ω(Tv1​,…,Tvn​).

T⋅ωT\cdot\omegaT⋅ω 仍为交错 nnn 重型，故存在唯一 det⁡T\det TdetT 使

T⋅ω=(det⁡T)ω.T\cdot\omega=(\det T)\omega.T⋅ω=(detT)ω.

若换成 cωc\omegacω，两边同时乘 ccc，所以定义与归一化无关。

乘法性

对复合 STSTST，

ω(STv1,…,STvn)=(det⁡S)ω(Tv1,…,Tvn)=(det⁡S)(det⁡T)ω(v1,…,vn).\begin{aligned} &\omega(STv_1,\ldots,STv_n)\\ &\quad=(\det S)\omega(Tv_1,\ldots,Tv_n)\\ &\quad=(\det S)(\det T)\omega(v_1,\ldots,v_n). \end{aligned}​ω(STv1​,…,STvn​)=(detS)ω(Tv1​,…,Tvn​)=(detS)(detT)ω(v1​,…,vn​).​

由唯一性，$\det(ST)=\det S\det T$。

只用当前前提还能推出什么

恒等算子不改变输入，所以 det⁡I=1\det I=1detI=1。对标量算子 aIaIaI，多重线性性给出

ω(av1,…,avn)=anω(v1,…,vn),\omega(av_1,\ldots,av_n)=a^n\omega(v_1,\ldots,v_n),ω(av1​,…,avn​)=anω(v1​,…,vn​),

故 $\det(aI)=a^n$；特别地，非零维空间上的零算子行列式为零。这些结论仍只使用交错多重线性型和算子复合。

结论

本步骤建立的是行列式的坐标无关定义、归一化无关性和复合乘法性，恰好只依赖尾结点“交错型”和“算子”。可逆判据还要调用有限维单射/满射与基；Leibniz 公式要调用矩阵和基；特征值乘积还要调用上三角化与代数重数。那些性质保留在行列式概念页中，但不能倒过来伪装成本步骤的前提。定义本身要求有限维同空间算子，不能给非方映射强加同一个标量。
