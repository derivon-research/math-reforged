# $\mathbb R^n$ 中的 Cauchy-Schwarz 不等式

对任意 $v,w\in\mathbb R^n$，

$$
|v\cdot w|\leq \|v\|_2\|w\|_2.
$$

若两个向量都非零，把点积写成 $v\cdot w=\|v\|_2\|w\|_2\cos\theta$，再用 $|\cos\theta|\leq1$ 即得不等式。含零向量时两边同时为零。

等号成立当且仅当其中一个向量为零，或二者共线。绝对值允许同向和反向两种共线情形。

本节点记录实坐标版本；它与更一般内积空间中的同名定理具有相同结构，但不自动扩大本章来源的作用域。

> 来源：Strang, 5th ed., §1.2, pp. 16-17；代数验证见 Problem 1.2.22, p. 20。
