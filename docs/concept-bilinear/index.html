双线性型

节点范围： 本节点只表示双线性型。二次型由 q(v)=β(v,v)q(v)=\beta(v,v)q(v)=β(v,v) 构造，是独立节点。

同时接收两个向量的线性测量

映射 Γ:V×W→U\Gamma:V\times W\to UΓ:V×W→U 若固定任一变量后对另一个变量线性，称为双线性映射。若 U=FU=\mathbb FU=F 且两输入都来自 VVV，称为双线性型 β:V×V→F\beta:V\times V\to\mathbb Fβ:V×V→F。

在复空间中，双线性型对两个变量都线性，因此不同于内积；内积对一个变量共轭线性。
