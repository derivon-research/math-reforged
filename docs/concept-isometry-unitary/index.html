等距映射

节点范围： 本节点只表示保持内积（等价地保持范数）的线性映射。幺正算子是同一空间上的等距算子，已经拆成独立节点。

保持长度会保留多少几何信息

线性映射 T∈L(V,W)T\in\mathcal L(V,W)T∈L(V,W) 若对所有 vvv 满足

∥Tv∥=∥v∥,\|Tv\|=\|v\|,∥Tv∥=∥v∥,

称为等距映射。它不只是保持每个向量的长度；通过极化恒等式，它还保持内积：

⟨Tu,Tv⟩=⟨u,v⟩.\langle Tu,Tv\rangle=\langle u,v\rangle.⟨Tu,Tv⟩=⟨u,v⟩.

所以正交关系、夹角和规范正交组都被保持。

幺正算子

对同一有限维内积空间上的算子 T∈L(V)T\in\mathcal L(V)T∈L(V)，以下条件等价：

  1. TTT 保持内积；
  2. TTT 保持范数；
  3. $T^*T=I$；
  4. $TT^*=I$；
  5. TTT 可逆且 $T^{-1}=T^*$；
  6. TTT 把某组（等价地每组）规范正交基映成规范正交基。

满足这些条件的算子称为幺正算子；实内积空间中也常称正交算子。

为什么有限维同空间很重要

保持范数立即推出单射，因为 Tv=0Tv=0Tv=0 时 ∥v∥=0\|v\|=0∥v∥=0。在同维有限空间中，单射进一步推出满射，所以才有逆算子。若 T:V→WT:V\to WT:V→W 且 dim⁡W>dim⁡V\dim W>\dim VdimW>dimV，它可以是等距嵌入但不满射，不能写成 TT∗=IWTT^*=I_WTT∗=IW​。
