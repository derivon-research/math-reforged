# 矩阵-向量乘积

设 $A=[a_1\ \cdots\ a_n]$ 是 $m\times n$ 矩阵，$x=(x_1,\ldots,x_n)^T$。矩阵乘向量定义为列向量的线性组合：

$$
Ax=x_1a_1+\cdots+x_na_n\in\mathbb R^m.
$$

同一个结果也可逐行计算：$Ax$ 的第 $i$ 个分量是 $A$ 的第 $i$ 行与 $x$ 的点积。列视角说明输出能到达哪些向量；行视角直接给出每个输出分量。两种算法使用相同数字，但回答不同的结构问题。

> 来源：Strang, 5th ed., §1.3, pp. 22-23；§2.1, pp. 31-40 系统比较行图像、列图像与两种乘法算法。
